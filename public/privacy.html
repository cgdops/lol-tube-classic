LoL Tube Classic — Privacy Policy & YouTube API Compliance

Effective Date: July 30, 2026 • Status: Fully YouTube API Services Compliant
✓ Strict Zero-Data Retention & YouTube API Developer Policy Compliance Guarantee

LoL Tube Classic ("we", "our", or "the application") is an independent non-commercial web application dedicated to archiving classic 2009–2013 League of Legends YouTube content. We are committed to protecting user privacy and adhering strictly to Google & YouTube API Developer Policies.

1. Zero Personal Data Collection & Storage

We do not collect, capture, store, or ask for any personally identifiable information (PII) such as names, email addresses, IP addresses, passwords, or personal identity profiles. No user account registration or login is required to access the application.

2. Zero Data Sale or Monetization

We do not sell, rent, license, trade, share, or monetize user data with third-party advertisers, data brokers, tracking companies, analytics networks, or marketing partners under any circumstances.

3. YouTube API Services & Google Privacy Compliance Notice

LoL Tube Classic uses YouTube API Services to retrieve and display public video metadata, thumbnails, titles, channel names, and published dates. By accessing or using this application, users agree to be bound by the official terms and policies of YouTube and Google:

  • YouTube Terms of Service:
    https://www.youtube.com/t/terms
  • Google Privacy Policy:
    http://www.google.com/policies/privacy

Notice: This application accesses YouTube API Services exclusively to fetch public video catalog metadata. We do not request, access, store, or modify any user YouTube account credentials or private profile data.

4. User Data Deletion & Access Revocation Policy

Because LoL Tube Classic does not collect, record, or store user data, we maintain zero persistent user records to delete.

  • Clearing Local Browser Cache: Temporary search results cached in your browser's local sessionStorage can be deleted immediately by clearing your web browser cache or closing your browser tab.
  • Revoking Google Access Permissions: You can view, manage, or revoke access permissions granted to third-party applications at any time via the official Google Security Settings page:
    https://security.google.com/settings/security/permissions

5. Local Browser Session Storage

To optimize performance and minimize YouTube API network calls, temporary search query responses may be stored in your web browser's local session memory (sessionStorage). This cached data remains exclusively on your own personal device and is automatically erased when your browser tab is closed.
